# Gifts

## Overview
Gifts are items given to villagers to affect friendship. Each villager has individual preferences, and universal gift categories apply with exceptions.

## Gift preference levels
A villager can generally:
- Love an item
- Like an item
- Dislike an item
- Hate an item

The friendship result depends on the villager's preference and other gift-related rules.

## Universal gifts
The wiki defines universal gift groups, but individual villager tastes can override universal rules.

Examples of universal categories include:
- many universal likes
- universal dislikes
- universal hates
- universal loves

Always use the individual villager's preference when a specific preference is available.

## Examples
### Abigail
Amethyst is a notable loved gift for Abigail.

### Krobus
Pumpkin is a notable loved gift for Krobus.

### Willy
Pumpkin is a notable loved gift for Willy.

## Gift frequency
Gift-giving is constrained by the game's friendship/gift rules, including a weekly limit for normal gifts. Birthday gifts have special importance because their friendship effect is multiplied.

## Best practice for a RAG system
Store gift knowledge as entity-level records, for example:

Villager: Abigail
Item: Amethyst
Preference: Loved

This makes questions such as "What does Abigail love?" easier to retrieve.
