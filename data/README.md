# Stardew Valley RAG Knowledge Base

This corpus is designed for a beginner-friendly Retrieval-Augmented Generation (RAG) project.

## Scope
The files summarize core Stardew Valley gameplay knowledge in a retrieval-friendly Markdown format:
- crops
- villagers
- gifts
- items
- locations
- recipes
- fishing
- mining
- monsters
- farming
- animals
- buildings
- festivals
- quests
- seasons
- game mechanics

## Source policy
Facts in this corpus are based on:
1. The official Stardew Valley Wiki, hosted by ConcernedApe: https://stardewvalleywiki.com/
2. Official Stardew Valley / ConcernedApe pages on https://www.stardewvalley.net/

The official wiki is community-edited and hosted/maintained by ConcernedApe. Because wiki pages can change, treat the source URLs and version notes as part of the metadata.

## Version
The wiki currently identifies Stardew Valley 1.6.15 as the PC version documented in its main wiki header. The corpus therefore targets the 1.6.x game rules and should be refreshed if a newer gameplay version changes the facts.

## Important
This is a curated knowledge corpus, not a mirror of the entire wiki. The official wiki contains thousands of articles. For a production-quality RAG, ingest individual official-wiki pages or an approved export/API rather than copying the whole site.

## Suggested metadata
Each document can be assigned:
- source_file
- category
- version
- source_url
- entity
