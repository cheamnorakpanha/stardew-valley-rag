# Items

## Overview
Stardew Valley contains many item categories used for farming, fishing, mining, combat, cooking, crafting, gifting, quests, and collection.

## Major item categories
- Tools
- Weapons
- Hats
- Footwear
- Rings
- Foraged items
- Fish
- Bait
- Tackle
- Fertilizer
- Cooking ingredients and dishes
- Crafting materials
- Trees and tree products
- Secret Notes
- Books
- Artifacts
- Minerals
- Furniture
- Wallpaper
- Flooring

## Item data useful for RAG
For each item, useful fields include:
- item name
- category
- description
- season
- location
- acquisition method
- sell price
- energy
- health
- uses
- recipes
- gift preferences
- quest usage
- bundle usage

## Example: Pumpkin
- Category: Vegetable / Crop
- Season: Fall
- Base sell price: 320g
- Can be used in cooking and crafting-related recipes.
- Can be used in Community Center bundles.
- Can be given as a gift; its preference depends on the villager.

## Example: Amethyst
- Category: Mineral
- Commonly associated with mining/geode acquisition.
- Can be used as a gift.
- It is a loved gift for Abigail.
